# RS485 总线拓扑与 Modbus RTU 规约

## 拓扑：一主多从（手拉手菊花链）

```
   [QT5上位机/网关]  主站
   USB-RS485转换器
        │ A/B
   ┌────┴───────────────────────────────────────────┐
   │  120Ω                                            120Ω
  [终端]                                            [终端]
   │                                                  │
 ┌─┴──┐    ┌────┐    ┌────┐         ┌────┐
 │节点1│───│节点2│───│节点3│── ... ──│节点N│
 │addr1│    │addr2│    │addr3│         │addrN│
 └─────┘    └────┘    └────┘         └─────┘
   房间1      房间2      房间3           房间N
```

## 布线规则

1. **手拉手菊花链**：A 接 A、B 接 B，一根双绞线串起所有节点，不要接成星型。
2. **终端电阻**：只在总线**物理两端**各接一个 120Ω，中间节点不接。短距离(<10m)可省。
3. **共地**：非隔离方案所有节点 GND 必须连通，否则电平参考漂移导致通信异常。
4. **A/B 别接反**：接反则整条总线不通；不确定时可试接，全不通就调换 A/B。
5. **线材**：用 RVSP 屏蔽双绞线，屏蔽层单端接地，长距离抗干扰更好。
6. **一主多从**：同一时刻只允许一个从站发送，由主站轮询各地址，避免总线冲突。

## Modbus RTU 通信参数

| 项 | 值 |
|----|----|
| 波特率 | 9600（可配 19200） |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |
| 帧间隔 | ≥ 3.5 字符时间（判帧用） |
| CRC | CRC16，多项式 0xA001，低字节在前 |
| 从站地址 | 1~N（每房间唯一，固件/拨码配置） |

## 帧结构

```
请求: [地址1][功能码1][数据N][CRC-L][CRC-H]
响应: [地址1][功能码1][数据N][CRC-L][CRC-H]
异常: [地址1][功能码|0x80][异常码][CRC-L][CRC-H]
```

支持功能码：0x01 读线圈 / 0x03 读保持 / 0x04 读输入 / 0x05 写单线圈 / 0x06 写单寄存器 / 0x10 写多寄存器。

寄存器与线圈定义见 [docs/modbus-map.md](../docs/modbus-map.md)。

## 半双工方向切换（关键）

- 发送前拉高 DE/RE，**必须等最后一个字节完全移出（TC 发送完成标志）**再拉低切回接收；
  用 TXE（发送寄存器空）会截断末字节。
- ESP32-S3 可用 `uart_set_mode(UART_MODE_RS485_HALF_DUPLEX)` 让硬件自动控制 DE，省心。

## 典型交互示例（主站读节点1的心率等10个输入寄存器）

```
主站->从站: 01 04 00 00 00 0A F1 CD
从站->主站: 01 04 14 [20字节数据] [CRC]
```
